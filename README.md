# Anti-Stress Clicker

Командний навчальний проєкт.

Система зниження стресу з особистим кабінетом,
методами боротьби зі стресом, статистикою
та інтеграцією з пристроями.

## Команда

- АП — особистий кабінет та індивідуальна аналітика
- МЛ — методи боротьби зі стресом
- ОО — загальний моніторинг та статистика
